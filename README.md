# Hari Prasath Portfolio

This is a static HTML portfolio. `index.html` is the homepage and should remain in the project root for Vercel.

## Folders

- `assets/images/` - portfolio photos and project cover images
- `assets/documents/` - current resume PDF
- `case-studies/` - standalone project case study pages

## Vercel

Deploy from the repository root. For a static HTML project, use the **Other** framework preset, leave the build command empty, and serve the root directory so Vercel can find `index.html`.
